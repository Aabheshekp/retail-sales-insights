# Retail Sales Insights

An interactive Streamlit dashboard for transaction analysis. Includes revenue and order KPIs, date/category/region filters, monthly trends, category and regional charts, downloadable filtered data, and a fictional sample ledger.

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

Upload a CSV with the schema in [the data dictionary](docs/DATA_DICTIONARY.md).
